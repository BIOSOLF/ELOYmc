🛠️ Prérequis
-------------

Avant d'installer le modpack, assurez-vous d'avoir :

1.  **Minecraft** (Launcher Officiel ou Launcher alternatif / hors ligne comme SKlauncher \[testée fonctionnelle sur la version 1.3 des deux modpacks\] ).
    
2.  **Java 17.**
    
3.  **Forge loader**.
    

📥 Guide d'installation étape par étape
---------------------------------------

### Étape 1 : Installer le Mod Loader (Forge)

1.  Téléchargez l'installateur correspondant à votre version de Minecraft DES CLIENT \[SKLUNCHER par exemple\] PROPOSE LA CONFIGURATION DE FORGE DURANT LA CONFIGURATION :
    
    *   **Forge :** [https://files.minecraftforge.net/](https://files.minecraftforge.net/)
        
2.  Lancez le fichier .exe ou .jar téléchargé.
    
3.  Choisissez **Client**, sélectionnez la bonne version de Minecraft (1.20.1) puis cliquez sur **Installer**.
    
4.  Une fois l'installation terminée, ouvrez votre launcher Minecraft. Un nouveau profil (ex: Fabric-Loader-1.20.1) doit être disponible.
    

### Étape 2 : Installer les Mods

1.  Téléchargez la version du modpack de votre choix (.zip) dans la section **release** de ce projet.
    
2.  Extrayez le contenu du fichier .zip sur votre PC.
    
3.  Accédez à votre dossier de jeu .minecraft :
    
    *   **Windows :** Appuyez sur Touche Windows + R, tapez _%appdata%\\.minecraft_ et validez.
        
    *   **Mac :** Dans le Finder, faites Cmd + Shift + G et entrez _~/Library/Application Support/minecraft_
        
    *   **Linux :** Visez _~/.minecraft_
        
4.  Ouvrez le dossier mods (s'il n'existe pas, créez un dossier nommé _mods_ en minuscules).
    
5.  Copiez tous les fichiers .jar extraits dans ce dossier mods.
    

🚀 Guide pour les Launchers Crack (Exemple : SKlauncher)
--------------------------------------------------------

Si vous utilisez un launcher alternatif comme **SKlauncher** :

1.  Ouvrez **SKlauncher**.
    
2.  Dans le menu des profils, créez un **Nouveau Profil**.
    
3.  Dans la liste des versions :
    
    *   Choisissez la version **Forge** installée à l'étape 1 (ou utilisez le gestionnaire d'installateurs intégré dans le launcher s'il le propose).
        
4.  Cliquez sur **Sauvegarder le profil**.
    
5.  Cliquez sur le dossier de jeu ou accédez à _%appdata%\\.minecraft_ (ou _le dossier d'instance de votre launcher_) et placez les mods dans le dossier mods.
    
6.  Lancez le jeu !
    

❓ Problèmes fréquents & Dépannage
---------------------------------

*   **Le jeu plante au démarrage (Crash) :**
    
    *   Vérifiez que vous avez bien installé le bon mod loader (Fabric vs Forge).
        
    *   Assurez-vous que le dossier mods ne contient pas de doublons ou de mods d'une ancienne version.
        
    *   Si vous utilisez la version _Complete_, vérifiez que le mod Fabric API est bien présent.
        
*   **Erreur de version Java :**
    
    *   Mettez à jour votre version de Java \[1.20.1\] depuis le site officiel d'Oracle ou d'Adoptionium.
